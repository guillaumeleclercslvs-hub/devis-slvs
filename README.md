Carnet de devis SLVS
Application de devis pour tuyauterie et chaudronnerie industrielle (SLVS).
Fonctionnalités
Sélection client (avec ajout rapide de nouveaux clients)
Description du devis avec dictée vocale
Catalogue matériel par catégorie (tuyauterie, chaudronnerie, supportage, location) avec prix
Calcul main d'œuvre (heures, heures samedi, étude)
Sous-traitants et fournitures avec marges appliquées automatiquement
Tarifs horaires et marges modifiables
Notes et remarques
Export du devis en PDF (via impression du navigateur) et en texte
Installation sur mobile / ordinateur
Ce site peut s'installer comme une application (PWA) :
iPhone : ouvrir le lien dans Safari → Partager → "Sur l'écran d'accueil"
Windows : ouvrir le lien dans Edge ou Chrome → bouton "Installer" dans la barre d'adresse
Usage
Aucune installation technique requise, tout fonctionne directement dans le navigateur.
